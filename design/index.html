Taskly

Design prototype

Static HTML — no framework, no build step, no network calls. It is the visual spec the React app builds against: every value comes from assets/tokens.css, which is mirrored as oklch variables in src/index.css. Colour direction is taken from moodboard/.

Screens

Sign in Split card, form left and illustration right. Toggle the generic-401 error state. Create account Same frame, with the password hint and the duplicate-email 409 on the field. Workspace Projects on the left; pick one and its tasks fill the right. Tabs, task detail with comments, members, labels, dialogs and every list state.

Palette

The moodboard's teal is #24C0B8. At 2.26:1 against white it cannot carry text or a focus ring, so it stays the brand accent — washes, the active-project marker, the illustration — while --primary is the deeper #0A7F78 (4.86:1).
